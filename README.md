A one-line sport the Olympics turned down, written to be read aloud by a broadcaster keeping a straight face. `main.py` scores twelve hand-written candidates against the judge's brief, picks the strongest, and writes it to `/output/entry.txt`:

> Competitive Hide and Seek: the final was abandoned after eleven days — nobody could find the defending champion.

Run it:

```sh
python3 main.py
```
